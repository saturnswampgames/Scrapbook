# Scrapbook — Editable Digital Diary

A tactile, editable digital scrapbook with an animated book cover, page-turn transitions, editable writing, photo uploads, movable decorations, and browser-local saving.

## Features

- Opening-cover and page-turn animations
- Three designed double-page spreads
- Inline text editing
- Click-to-upload photo placeholders
- Drag-and-drop scrapbook decorations
- Addable stickers
- Automatic local browser saving
- JSON backup export/import
- Responsive layout and keyboard navigation
- Reduced-motion support

## Run locally

Open `index.html` directly or serve the folder with any static file server.

## Deploy to Vercel

This is a static site with no build command. Import the GitHub repository into Vercel and use the default deployment settings.

## Editing

Select **Edit scrapbook**, then click outlined text, click photo placeholders to upload images, and drag outlined decorations. Edits remain in the current browser using `localStorage`; use **Export backup** for a portable JSON copy.
